# ELP_Data_Wrangling
Python data wrangling and EDA pipeline for noisy psycholinguistic behavioral data, inspired by the English Lexicon Project (ELP)


### About This Project

This project demonstrates practical **data wrangling, cleaning, and Exploratory Data Analysis (EDA)** skills using a dataset modeled after the structure of the **English Lexicon Project (Balota et al., 2007)**. 

Real-world psycholinguistic data is inherently noisy. To showcase my programmatic data literacy, I simulated a raw dataset containing realistic psycholinguistic variables (e.g., Word Length, Morphological Complexity), as well as missing values, hardware error outliers, and low-accuracy trials. 

The Python pipeline in this repository successfully cleans this raw behavioral data and visualizes classic cognitive phenomena—specifically, the **Word Length Effect** and **Morphological Complexity Effect** on visual word recognition.

**Data Source & Reference:**
* Balota, D. A., Yap, M. J., Cortese, M. J., Hutchison, K. A., Kessler, B., Loftis, B., ... & Treiman, R. (2007). The English Lexicon Project. *Behavior Research Methods*, 39(3), 445-459.
